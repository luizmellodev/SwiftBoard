# Examples (maintainers)

Not part of the published SwiftBoard package. Needs sibling
`../../SwiftDS/package`.

```bash
cd Examples
swift run SwiftBoardKitDemo
```

iOS Simulator: from repo root, `Scripts/run-ios-demo.sh`.

Copy [`SwiftDSCatalogRegistrar.swift`](SwiftDSCatalogRegistrar.swift) into apps
that depend on both SwiftBoard and SwiftDS.
